# Reliable Agent Harness

一个从零开始构建的最小化 Agent Harness，用于学习和实验可靠的 Agent 工程。

## 目标

本项目主要探索 Agent Harness 如何提供以下能力：

- 工具执行边界
- Agent 循环
- 护栏机制
- 验证机制
- 状态管理
- 上下文管理
- 评估
- 沙箱化执行

## 当前状态

目前正在构建 V0：一个带有手写 Agent 循环和受限工具集的最小化 Coding Agent。

## 路线图

- [ ] V0 - 最小化 Agent 循环
- [ ] V1 - 工具注册机制与执行限制
- [ ] V2 - 验证与重试
- [ ] V3 - 运行追踪
- [ ] V4 - 状态与检查点机制
- [ ] V5 - 上下文管理
- [ ] V6 - Docker 沙箱
- [ ] V7 - 评估基准
